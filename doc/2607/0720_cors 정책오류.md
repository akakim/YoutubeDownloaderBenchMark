
[문제점]

STT를 구현하여, 

XXX.mp4를 shorts_age(리액트 서버)에 올리면, source.mp4,metadata.json,audio.mp3 파일로 올리는 express의 역할은 끝이났다.
여기서 audio.mp3 파일을 읽어들여 translation.srt 파일까지 변환하는데 성공함.

근데, 이 translation.srt파일을 shorts_age 화면에서 다운받기 위해서 ai_server에는 다음 내용을 추가하니 문제가 생긴다. 


[추가된 소스코드 내용]

[해결책]


1. 먼저 Backend에서 Middleware에서 설정을 확인한다. 

[Request URL과 Origin 체크목록 1]
여기서 Content-Dispostion을 넣었더니 생기는게 cors policy 오류가 생긴다. 

이 헤더는 ai_server에서 shorts_age 쪽으로 주는 헤더이기 때문에 
먼저 이 설정이 추가해야한다. 

```
app.add_middleware(
    ...
    expose_headers=[
        "Content-Disposition",
    ]
    ...
)
```

2. 1번에서 된걸 확인한뒤, OPTIONS 상태 코드를 확인한다. (예시)
curl -i -X OPTIONS "http://localhost:5175/stt" -H "Origin: http://localhost:5173" -H "Access-Control-Request-Method: POST" -H "Access-Control-Request-Headers: authorization,content-type"
