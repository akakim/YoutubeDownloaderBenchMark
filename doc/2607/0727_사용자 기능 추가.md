Q: 사용자,관리자,소유자로 유저를 만들어야겠음. 소유자는 최상위 권한자임 

A: 좋아. 3단계 RBAC 권한 구조로 만들면 되겠네.

역할	주요 권한
USER	본인 정보·본인 작업만 조회/수정
ADMIN	사용자 관리, 전체 작업 조회, 운영 처리
OWNER	관리자 임명·해제, 시스템 설정, 모든 권한

권한 관계는 다음처럼 잡으면 깔끔해.

OWNER > ADMIN > USER

DB에는 우선 이렇게 넣으면 충분해.

ROLE VARCHAR2(20) DEFAULT 'USER'
CHECK (ROLE IN ('USER', 'ADMIN', 'OWNER'))

중요한 규칙은 서버에서 강제해야 해.

회원가입 시 무조건 USER
ADMIN 지정·해제는 OWNER만 가능
OWNER 계정 생성은 일반 API로 불가능
관리자도 OWNER를 수정·정지·삭제할 수 없음
최소 1명의 OWNER는 항상 유지
본인의 권한을 임의로 높일 수 없음
화면 숨김이 아니라 Spring Security에서 API 접근을 차단

```
@PreAuthorize("hasRole('OWNER')")
@PostMapping("/users/{id}/role")
public void changeRole(...) {
}

```

처음에는 users.role 컬럼 하나로 시작하고, 나중에 권한 종류가 많아질 때만 roles, permissions 테이블로 분리하면 돼. 현재 규모에서는 복잡한 권한 테이블보다 USER·ADMIN·OWNER enum 방식이 딱 적당해.
