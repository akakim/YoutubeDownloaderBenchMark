260601 현재 기획은

1. 유튜브에 올라온 롱폼 영상을 다운로드 받아서

2. 거기에 담긴 음성인식을 한 다음 
3. 자동으로 자막을 달아서

4. 캡컷 드래프트를 만드는 것이 최종 목표이다.



캡컷 드래프트를 만들기 위해, 서버에 올려놓은 동영상을 Text를 출력할 것이다.

1. 서버에 올려놓은 파일이 /upload url을 호출할 때 파일명이 공유되어야함.
2. 서버에 올려놓은 영상을 인식하여, Text로 변환함.
3. 이 Text의 산출물로 srt파일을 만들면 완성.


현재 STT를 구현하는 서비스를 보면 
1. OpenAI Whisper API
2. 브라우저 Web SpeechAPI
3. 클라우드 API(Google Cloud, Naver Cloud)
4. 로컬 오픈소스 모델 (오프라인, 무료)

이 중 4번이 매력적이다. 
1번과 4번에 대해서 개발 검토를 할 예정이다. 


/upload 책임:
MP4 받기 → source.mp4 저장 → metadata.json 생성 → jobId 반환

/api/convertJob 책임:
jobId 받기 → source.mp4 확인 → audio.mp3 생성 → metadata 상태 업데이트 → 결과 반환
